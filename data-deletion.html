데이터 삭제 안내

User Data Deletion Instructions · 그런트제로(GRUNT ZERO)

그런트제로 앱에 연결한 Instagram·YouTube 계정의 데이터를 삭제하고 싶으시면 아래 방법으로 요청해 주세요.

1. 이메일로 삭제 요청하기

받는 곳: grnt@grntzero.com
제목: 데이터 삭제 요청
본문: 연결한 계정 이름(Instagram 사용자 이름 또는 YouTube 채널 이름)
  • 요청을 받은 날부터 7일 이내에 해당 계정에서 받은 데이터를 모두 삭제합니다.
  • 삭제를 마치면 확인 답장을 이메일로 보내 드립니다.

2. Instagram에서 앱 연결 해제하기

  1. Instagram 앱에서 프로필 → 오른쪽 위 메뉴(≡) → 설정
  2. 앱 및 웹사이트 선택
  3. 그런트제로 앱을 찾아 제거

연결을 해제하면 회사는 더 이상 새 데이터를 받을 수 없습니다. 이미 받은 데이터까지 지우려면 위 1번 방법으로 요청해 주세요.

3. YouTube(Google)에서 연결 해제하기

Google 계정 관리 → 보안 → 타사 액세스 → 그런트제로 앱 선택 → 액세스 삭제 (myaccount.google.com/permissions)

자세한 내용은 개인정보처리방침을 확인해 주세요.

English — User Data Deletion Instructions

Request deletion by email

  1. Send an email to grnt@grntzero.com with the subject “데이터 삭제 요청” (Data Deletion Request).
  2. Include the name of the connected account (Instagram username or YouTube channel name).
  3. We will delete all data received from that account within 7 days and send you a confirmation reply.

Remove app access on Instagram

  1. Open Instagram → Profile → Menu (≡) → Settings
  2. Select Apps and Websites
  3. Find the GRUNT ZERO app and tap Remove

Remove access on Google/YouTube

Google Account → Security → Third-party access → select the GRUNT ZERO app → Remove access (myaccount.google.com/permissions).
